# Documentation ownership

- [Project README](../README.md) is the user entry point for scaffolding and legacy BatchCom commands.
- [Subsystem references](subsystems/README.md) describe current framework behavior and link its sources.
- [Code standards](code-standards.md) own conventions and behavioral acceptance. [Toolchain](toolchain.md) owns local checks, hooks, and CI.
- [Lessons](../LESSONS.md) records recurring development findings. [Agent Notes](../.agents/notes/README.md) holds long-lived framework decisions. Earlier ADRs and plans remain in the subsystem history.
- Documentation for generated BatchCom projects belongs [in the template](../rtmpl/templates/batchcom-research/README.md). Edit it when changing the legacy template contract.
- Use the [document checklist](../.agents/references/document-budgets.md) for changes. Apply the [experiment record guidance](../.agents/references/experiment-reports.md) when writing about actual research evidence.
