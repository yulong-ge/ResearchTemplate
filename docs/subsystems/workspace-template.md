# Research workspace

The [standard directory layout](../../README.md) works for new and existing
research topics. Optional documentation and maintenance tools are set up by an
Agent using the instructions printed by `rtmpl new`.

The [BatchCom template](../../rtmpl/templates/batchcom-research/README.md) remains
available for projects that use its environment paths and human Plan workflow.
Its [manifest](../../rtmpl/templates/batchcom-research/template.yaml) defines
the managed payload. Existing projects keep their local policies and paths.
