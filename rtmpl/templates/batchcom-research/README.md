# <proj>

> 由 `rtmpl` 的 `batchcom-research` 模板生成。初始化后先改 `AGENTS.md` 的「研究项目」部分，再把这里换成项目简介。

## 目录

| 位置 | 用途 |
|---|---|
| `AGENTS.md` | 给 Agent 看的项目说明：研究问题、方法、指标、代码入口、协作方式 |
| `docs/plans/` | 每个实验或工程任务一个 Plan |
| `experiments/<名字>/` | 日志、指标、配置、图表等原始产物 |
| `notes/` | 跟代码一起版本化的项目笔记，含 `environment.md` |
| `literature/notes/` | 论文笔记 |
| `paper/` | 论文稿件 |
| `external/` | 第三方代码（直接拷贝，不用 submodule） |
| `src/paths.py` | 项目存储路径 |
| `.rtmpl/` | 模板元数据，不要手动编辑 |
