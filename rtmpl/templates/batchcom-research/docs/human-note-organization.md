# Human Note Organization

This reference supports human-owned research workspaces. Read it when a Plan explicitly asks for
note organization.

## Default boundary

- A human writes the Plan and names the context files the Agent may read.
- The Agent proposes the file edits and waits for approval before changing notes.
- Experiment directories hold outputs named by the human. A Plan can define a directory naming
  convention and output format when the task benefits from one.
- The Agent reports observations and raw outputs. The human decides what they mean and where a
  durable note, paper section, or follow-up Plan belongs.

## Organizing a requested note edit

1. Read the repository instructions and the exact files named by the Plan.
2. Separate observed output, interpretation, proposal, and human decision.
3. Keep each durable fact in one human-chosen home; use a short pointer elsewhere instead of
   copying prose.
4. Preserve uncertainty and provenance. Do not infer approval, completion, causality, or novelty
   from an Agent action or a favorable metric.
5. Show the proposed file list and unresolved conflicts before a broad reorganization.

Routine experiment execution leaves notes unchanged. The human names the file and intended
correction for any historical note edit.
