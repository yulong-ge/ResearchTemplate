# alphaXiv OpenCode commands

Slash commands (`/alphaxiv research`, `/alphaxiv paper`, `/alphaxiv feed`, `/alphaxiv assistant`) that drive the `alphaxiv` CLI for paper discovery, inspection, and AI-assisted synthesis.

Generated by `alphaxiv skill install --target opencode --scope project` (alphaXiv CLI v0.7.0). Re-run that command to update.

## Setup (one-time per machine)

These commands call the `alphaxiv` CLI, which is **not** a project dependency — install it globally so every project can use it:

```bash
uv tool install alphaxiv-py
alphaxiv --version        # expect: alphaXiv CLI, version 0.7.0+
```

Authenticate with an API key (create one at https://www.alphaxiv.org → Profile → User Settings → API Keys):

```bash
export ALPHAXIV_API_KEY="axv1_..."   # put in shell rc (chezmoi-managed, synced to servers)
alphaxiv auth status                  # verify the key
```

Most read commands (`search`, `feed`, `paper`, `overview`, `similar`) work without a key; `assistant` and write actions (comments, votes, folders) require it.

## Updating

```bash
uv tool upgrade alphaxiv-py
alphaxiv skill install --target opencode --scope project --force
```

## Agent usage flow

`search` (keyword lookup) → `feed` (recent/ranked discovery) → `paper` (inspect one) → `assistant` (synthesis/follow-up). Prefer deterministic retrieval before the assistant. Add `--json` for machine-readable output.
